# Architecture Decision Records

This directory contains ADRs — documents for decisions that are:

1. **Hard to reverse** — changing your mind later has meaningful cost
2. **Surprising without context** — a future reader would wonder "why did they do it this way?"
3. **The result of a real tradeoff** — there were genuine alternatives and you picked one for specific reasons

If all three aren't true, skip the ADR.

Use the template in `/templates/ADR.md`. Name files `NNNN-short-title.md`.
